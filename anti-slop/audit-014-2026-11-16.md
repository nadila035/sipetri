# Audit 014: Sinkronisasi Seluruh Halaman Admin dengan Halaman Staf

Tanggal: 2026-11-16
Lingkup: audit baca-saja terhadap seluruh tampilan Admin (`Header`, `Sidebar`, `Dashboard Monitoring`, `MonitoringOverview`, `Verifikasi Laporan Triwulan`, `Verifikasi Sasaran Kinerja`, `Arsip dan Rekapitulasi`, `Periode dan Tenggat Waktu`, serta Modal Pemeriksaan Admin) dibandingkan dengan seluruh halaman Staf (`Dashboard`, `InputLaporanTriwulan`, `InputSasaranKinerja`, `RiwayatLaporan`, `DetailModal`).
Mode: `after` (pilihan sesi pengguna). Belum ada file kode aplikasi yang diubah hingga pengguna menyetujui nomor temuan yang ingin diperbaiki.

## Daftar Temuan

1. **HIGH: Penghitung di Header Admin dan indikator menu di Sidebar belum sesuai tugas Admin (R-27, R-17).**
   - Bukti: `src/components/Header.tsx:38-46` menampilkan jumlah dokumen berstatus `"Revisi"` (`"... perlu revisi"`), padahal menindaklanjuti `"Revisi"` adalah tugas Staf (`StaffNotifications`) sedangkan antrean kerja Admin adalah dokumen berstatus `"Menunggu"` verifikasi. Selain itu `src/components/Sidebar.tsx:60-79` baru memberi titik penanda (`nav-dot`) untuk draf Staf dan belum memberi indikator antrean `"Menunggu"` pada menu `Verifikasi Laporan Triwulan` maupun `Verifikasi Sasaran Kinerja`.

2. **HIGH: Klik laporan di panel `MonitoringOverview` membuka pratinjau cetak alih-alih modal pemeriksaan Admin (R-26).**
   - Bukti: `src/pages/Admin.tsx:1238` meneruskan `onReview={(record) => setPreview(record)}` yang membuka `PrintPreviewModal`, bukan membuka modal pemeriksaan Admin (`setSelectedId(record.id)`), padahal `src/components/MonitoringOverview.tsx:60,73` memicu aksi `onReview` dari tombol `"Lihat laporan"` dan sel matriks triwulan.

3. **HIGH: Parser waktu kirim di panel `Dokumen Terbaru` Admin dan `reportingCoverage` tidak membaca format kiriman Staf (R-17, R-27).**
   - Bukti: Staf mengirim dan merevisi dokumen dengan `sentAt` memakai `new Date().toLocaleString("id-ID")` (`src/pages/InputLaporanTriwulan.tsx:428`, `src/pages/InputSasaranKinerja.tsx:550`, `src/utils/revision.ts:134`). Namun `sentAtTimestamp` di `src/pages/Admin.tsx:303-320` hanya mengenali format nama bulan huruf seperti `"18 Juni 2025, 10:24"` sehingga kiriman baru bernilai `0` dan gagal terurut ke atas di `Dokumen Terbaru`. Sebaliknya `reportingCoverage` di `src/utils/organizations.ts:60-71` hanya mengenali format angka/ISO dan mengembalikan `0` untuk format huruf awal.

4. **HIGH: Perhitungan sisa hari, progress bar, cakupan slot tahunan, dan label status pada kartu `Tenggat Aktif` Admin tidak sinkron dengan Dashboard & form Staf (R-17, R-27).**
   - Bukti: Staf (`src/pages/Dashboard.tsx:170-196` lewat `getDeadlineCardModel` di `src/utils/workflow.ts:270-355`) menghitung sisa hari berbasis kalender `Asia/Jakarta` (tampil `"Hari ini"` saat 0), progress dari `startDate` ke `deadline`, dan menyembunyikan hitungan hari saat periode ditutup/belum dibuka. Sementara `src/pages/Admin.tsx:377-404, 1154-1169, 1431-1485` memakai `Math.ceil` jam, progress dari `quarterStart` `Date.UTC` murni, tetap menampilkan `"hari tersisa"` / `"hari terlewat"` saat periode `closed` atau `upcoming`, serta belum menampilkan status periode tahunan (`${year}-annual`) untuk `Sasaran Kinerja`. Label `periodStatusLabel` (`src/pages/Admin.tsx:513-530`: `"Tanggal Tidak Valid"`, default `"Belum Dibuka"`) juga berbeda dengan `formatPeriodStatusTag` pada form Staf (`src/utils/workflow.ts:151-164`: `"Jadwal Invalid"`, default `"Ditutup"`).

5. **HIGH: Tombol `Batal` dan `✕` pada modal pemeriksaan Admin memblokir penutupan modal ketika ada catatan revisi yang diketik (R-26, R-27).**
   - Bukti: `src/pages/Admin.tsx:222-225, 250-252, 1841` mendaftarkan catatan modal ke `useUnsavedChanges` dan memanggil `confirmNavigation()` (alert penolakan) di `closeReview`, berbeda dengan `src/pages/RiwayatLaporan.tsx:580-606` yang memakai `window.confirm` agar pengguna bisa memilih keluar dan membatalkan perubahan.

6. **HIGH: Modal pemeriksaan Admin dan tampilan detail revisi Staf untuk `Sasaran Kinerja` serta rincian indikator belum sinkron (R-17, R-26, R-27).**
   - Bukti:
     - `getReviewPrograms` (`src/pages/Admin.tsx:61-108`) gagal memetakan multi-program jika `cursor !== record.items.length` (misalnya `SK-2025-001` pada `src/pages/RiwayatLaporan.tsx:70-95` yang memiliki 5 program di `criteriaData` namun 6 `items`, sehingga jatuh ke 1 program fallback).
     - Saat membuka dokumen berstatus `"Disetujui"` atau `"Revisi"`, daftar program di sisi kiri (`src/pages/Admin.tsx:1658-1660`) tetap menulis `"Belum diperiksa"` dan kartu indikator (`src/pages/Admin.tsx:1757-1765`) tidak menyorot `item.needsRevision` yang tersimpan.
     - Nilai `Link Evidence` hanya dirender sebagai teks biasa, nilai `Bulan Pelaksanaan` tampil mentah tanpa `formatBulanPelaksanaan` (`src/pages/Admin.tsx:1776`), di dalam modal belum tersedia tombol `Pratinjau / cetak` dan `Unduh Excel`, dan `Riwayat pemeriksaan` (`src/pages/Admin.tsx:1818`) hanya menulis `"Indikator N"` tanpa nama program/indikator.
     - Di sisi pasangan Staf (`src/components/DetailModal.tsx:126-141, 250-386`), tabel 7 kolom `criteriaData` untuk `Sasaran Kinerja` tidak menampilkan `item.note` hasil pemeriksaan Admin (`Admin.tsx:443-447`), sedangkan saat mode edit revisi tampil sebagai daftar datar `record.items`.

7. **HIGH: Filter `Triwulan` tampil di `Verifikasi Sasaran Kinerja`, dan pengaturan `Periode Default Beranda Staf` serta sakelar kartu periode belum menjaga konsistensi status periode (R-26, R-27).**
   - Bukti: `src/pages/Admin.tsx:259, 964-972` tetap menampilkan filter `Triwulan` di `Verifikasi Sasaran Kinerja` padahal periode `Sasaran Kinerja` berbentuk `"Tahun YYYY"`, sehingga memilih triwulan mengosongkan daftar. Pada menu `Periode dan Tenggat Waktu`, `handleSaveActivePeriod` (`src/pages/Admin.tsx:928-941`) dapat mengatur beranda Staf ke periode baru yang slotnya masih terkunci (`open: false`, `Admin.tsx:707-711`) tanpa peringatan, dan `handleCardToggleOpen` (`src/pages/Admin.tsx:554-600`) memanggil `clearSlotDraft(slotKey)` di baris `598` sehingga membuang editan tanggal yang belum disimpan tanpa konfirmasi.

8. **HIGH: Unit pada data awal `RiwayatLaporan.tsx` belum terdaftar di master `organizations.ts` sehingga memicu laporan tak terpetakan di seluruh halaman Admin (R-17, R-38).**
   - Bukti: `src/pages/RiwayatLaporan.tsx:31, 74, 232` memakai unit `"Bagian Perencanaan & Kinerja"` dan `"Bagian Keuangan"`, yang tidak tercantum di `unitOptions` (`src/utils/organizations.ts:3-15`), sehingga di Admin selalu memicu `coverage.unmapped > 0` (`src/pages/Admin.tsx:1183`) dan opsi `(belum dipetakan)` pada dropdown Unit (`src/pages/Admin.tsx:983-985`).

9. **MEDIUM: Warna badge status dan gaya daftar di Admin bertabrakan antarkomponen Admin serta tidak konsisten dengan halaman Staf (R-09, R-29).**
   - Bukti: di Admin, tabel dan `Dokumen Terbaru` (`src/pages/Admin.tsx:1414-1420, 1542-1551`, `src/admin.css:1551-1567, 1854-1878`) memakai biru untuk `Menunggu` (`.ongoing`) dan merah untuk `Revisi` (`.revision`), sedangkan kartu KPI Admin (`Admin.tsx:1204`), ikon `Dokumen Terbaru` (`Admin.tsx:1394`), dan `MonitoringOverview` (`src/components/monitoring-overview.css:6-12`) memakai amber/kuning untuk `Menunggu` dan merah untuk `Revisi` (di Staf sendiri `dashboard.css:10-12` memakai biru/amber sementara `Riwayat` `src/index.css:390-392` memakai amber/merah). Selain itu `Admin.tsx:1187` memakai `className="action-icon blue admin-kpi-icon"` alih-alih `.admin-kpi-icon-blue` (`src/admin.css:1709`), dan `Admin.tsx:1388` memakai `.activity-item` milik Staf sehingga mewarisi garis timeline vertikal dari `src/index.css`.

10. **LOW: Halaman `Arsip`, tabel Admin, ketahanan filter antar-menu, judul halaman, dan atribut aksesibilitas form Admin belum seragam dengan halaman Staf (R-31, R-15, R-20).**
    - Bukti:
      - `Arsip dan Rekapitulasi` (`src/pages/Admin.tsx:1492-1580`) belum memiliki tab jenis dokumen (`Semua`, `Laporan Triwulan`, `Sasaran Kinerja`) maupun ringkasan kartu status seperti `RiwayatLaporan.tsx`.
      - Tabel Admin (`src/pages/Admin.tsx:1522-1539`) hanya menampilkan `r.unit`, belum menyertakan unit induk (`parentUnit`) dan penyusun (`author`) yang direkam oleh form Staf.
      - `src/App.tsx:121` memasang `<Admin key={active} ... />`, sehingga filter pencarian, tahun, triwulan, unit, dan status otomatis ter-reset setiap Admin berpindah sub-menu.
      - `src/components/Header.tsx:32-35` mengulang `Beranda / {title}` pada `Dashboard Monitoring` dan `src/pages/Admin.tsx:1002-1011` mengulang `<h1>{active}</h1>` serta teks generik `"Data tersimpan di browser ini. Pergantian peran tidak memerlukan login."`, belum mengikuti pola judul dan subjudul kontekstual yang sudah dirapikan di halaman Staf.
      - Elemen input dan select pada filter Admin serta form `Periode dan Tenggat Waktu` (`src/pages/Admin.tsx:827-845, 943-997, 1083-1114`) belum memiliki atribut `id` dan `name` eksplisit seperti pada seluruh form Staf.

## Batas Verifikasi

- Pemeriksaan dilakukan melalui pembacaan langsung kode sumber dan gaya terkait (`Admin.tsx`, `MonitoringOverview.tsx`, `Header.tsx`, `Sidebar.tsx`, `App.tsx`, `Dashboard.tsx`, `InputLaporanTriwulan.tsx`, `InputSasaranKinerja.tsx`, `RiwayatLaporan.tsx`, `DetailModal.tsx`, `workflow.ts`, `organizations.ts`, `revision.ts`, CSS terkait).
- Belum ada modifikasi kode, build ulang, ataupun penjalanan ulang browser pada audit ini karena menunggu persetujuan nomor temuan dari pengguna.
