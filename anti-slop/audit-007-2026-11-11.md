# Audit konsistensi dropdown organisasi

Mode: after (session override). Lingkup hanya kedua kontrol organisasi dan keterangan unit independen.

1. **LOW — Panah dropdown tidak konsisten (R-04, C-1).** OrganizationSelect memakai karakter teks ⌄, sementara dropdown halaman lain memakai select native. Ganti dengan indikator chevron yang meniru bentuk, ukuran, warna, dan posisi panah dropdown existing, tanpa mengubah pencarian atau scroll.
2. **LOW — Tipografi kontrol dan pilihan perlu diselaraskan (R-06).** CSS komponen organisasi menetapkan gaya input dan opsi terpisah. Samakan keluarga font, ukuran, bobot, warna dan fokus dengan kontrol existing; jangan menebalkan opsi terpilih jika tidak sesuai referensi. Perubahan CSS hanya scoped pada komponen organisasi.
3. **LOW — Keterangan independen tidak diperlukan (R-15).** Hapus teks Unit Independen: subunit dan pelapor menggunakan nama ... dari JSX dan aturan CSS yang tidak lagi dipakai. Pertahankan subunit dan pelapor otomatis menggunakan nama induk.

Referensi diperiksa: src/index.css, .meta-control select, .parent-inputs select, .history-filters select; src/components/organization-select.css. Tidak mengubah kode implementasi sebelum persetujuan nomor temuan. Tidak mengusulkan perubahan halaman lain.
