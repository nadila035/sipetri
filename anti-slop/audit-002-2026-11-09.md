# Anti-Slop Audit — Review modal program and indicator panels

Scope: the program list and adjacent indicator review area in the **Periksa** modal. The existing modal header, review queue, filters, and other page sections are excluded.

## Findings

1. **LOW — Program list hierarchy differs from the reference and the dashboard's compact type system (R-05, C-1).** The current sidebar uses one plain heading and lightly highlighted navigation buttons. It does not show the actual program count or the reference's clear separation between the list heading, active row, and remaining rows. The list can use the existing `reviewPrograms` data for a dynamic count and retain program navigation.

2. **LOW — Indicator area typography and surfaces do not match the requested reference (R-11, C-1).** The current program heading and indicator labels use larger, darker text, while the list and cards lack the softer blue-gray hierarchy shown in the reference. The active program heading, small index labels, card borders, revision labels, and navigation controls can be restyled with the existing dashboard typography and palette without changing header or review behavior.

## Follow-up

Findings #1 and #2 were approved and resolved. The list now shows its live program count and has clearer active/inactive rows; the adjacent review area uses the dashboard's compact DM Sans hierarchy, blue-gray text, softer borders, and restrained blue accents. The modal header, review queue, filters, note state, and action handlers were left unchanged.

Validation: `npm.cmd run build` and `npm.cmd exec -- oxfmt --check src\\pages\\Admin.tsx src\\admin.css` pass. The modal was opened in the browser at desktop and mobile widths; no horizontal page overflow was observed at the mobile width.
