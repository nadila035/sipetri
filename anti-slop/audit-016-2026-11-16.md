# Audit 016: Alur Detail Modal dan Pemeriksaan pada Halaman Verifikasi Admin

Tanggal: 2026-11-16
Mode: `after` (pilihan sesi pengguna)
Lingkup: Perubahan pada `src/pages/Admin.tsx` dan `src/components/DetailModal.tsx`, serta pemeriksaan pasca-implementasi terhadap gaya dan aksesibilitas terkait (`src/index.css`, `src/admin.css`, `src/utils/useDialog.ts`). Belum ada perbaikan terhadap temuan audit di bawah ini sebelum pengguna memilih nomor temuan yang disetujui.

## Ringkasan Fitur yang Telah Diterapkan

1. **Kolom Aksi pada Kedua Halaman Verifikasi (`src/pages/Admin.tsx`)**
   - Pada menu `Verifikasi Laporan Triwulan` dan `Verifikasi Sasaran Kinerja`, kolom `Aksi` tabel kini hanya menampilkan satu tombol `Lihat Detail` (tanpa tombol `Periksa` atau `Pratinjau` langsung di baris tabel).
   - Menu `Arsip dan Rekapitulasi`, `Dashboard Monitoring`, `Periode dan Tenggat Waktu`, dan seluruh halaman Staf dipertahankan tanpa perubahan perilaku.
   - Klik `Lihat Detail` membuka komponen `DetailModal` (format 12 kolom untuk `Laporan Triwulan` dan format 7 kolom untuk `Sasaran Kinerja`, sama dengan detail modal pada halaman Staf) yang dirender di luar `.admin-page` agar tidak tertimpa aturan tabel/tombol khusus Admin.
2. **Tombol Footer Detail Modal Admin (`src/components/DetailModal.tsx`, `src/pages/Admin.tsx`, `src/index.css`)**
   - Pada mode `isAdmin` untuk kedua halaman verifikasi (`Verifikasi Laporan Triwulan` dan `Verifikasi Sasaran Kinerja`), tombol `Tutup` di kiri bawah dan tombol `Unduh Excel` dihapus karena penutupan modal sudah tersedia pada tombol `×` di kanan atas (serta backdrop/Escape).
   - Footer `.detail-actions.is-admin` diratakan ke kanan (`justify-content: flex-end` pada desktop dan grid 2 kolom pada layar `<= 440px`) dan selalu menampilkan tombol `Cetak` (membuka `PrintPreviewModal`) serta tombol `Periksa` (`canReview={true}`) untuk semua status (`Menunggu`, `Revisi`, dan `Disetujui`). Saat `Periksa` ditekan, dokumen berstatus `"Menunggu"` terbuka dalam mode pemeriksaan editable (`canEditReview === true`), sedangkan status `"Revisi"` dan `"Disetujui"` terbuka dalam mode baca-saja (`canEditReview === false`).
   - Pesan banner `.revision-alert` pada `DetailModal` disesuaikan saat `isAdmin` bernilai `true` (`"Dokumen dikembalikan untuk revisi"`), sedangkan tampilan dan footer untuk Staf tetap seperti semula.
3. **Transisi ke Halaman Pemeriksaan & Revisi Admin (`src/pages/Admin.tsx`)**
   - Menekan tombol `Periksa` pada footer `DetailModal` menutup `DetailModal` (`setDetailRecord(null)`) dan membuka modal pemeriksaan dokumen `.admin-review-overlay` (`openReviewModal(rec)`).
   - Footer `.admin-review-modal-footer` diringkas dengan menghapus tombol `Unduh Excel`, `Pratinjau / Cetak (PDF)`, dan `Batal` / `Tutup` (penutupan tetap melalui tombol `✕` kanan atas atau `Escape`). Pada status `"Menunggu"` hanya tampil `Kirim Revisi (N)` dan `Setujui Dokumen`, sedangkan pada status `"Revisi"` atau `"Disetujui"` footer hanya menampilkan ringkasan jumlah program dan catatan revisi tanpa tombol keputusan.
4. **Penyelarasan Tampilan Halaman `Periode dan Tenggat Waktu` (`src/pages/Admin.tsx`, `src/admin.css`)**
   - Kartu atas `Tahun Pelaporan` dan `Periode Default Beranda Staf` disamakan grid (`repeat(2, minmax(0, 1fr))`), radius `13px`, header dengan ikon lencana `.admin-kpi-icon` (`calendar` biru dan `clock` hijau) bergaya panel lain, tinggi input/select `36px`, serta tombol utama biru `#2864ca` dan tombol sekunder `#fff` / `#dce3eb` yang seragam dengan halaman lain.
   - Panel jadwal `Sasaran Kinerja Tahunan` dan `Triwulan I`–`IV` memakai header kartu `#fafbfd`, judul `15px` `Manrope` `#18253c`, kicker `#2965d4`, sakelar biru `#2864ca` (dengan hit area sentuh `54x44px` via `::before`), lencana status berbentuk pill selaras `.status-chip`, serta tinggi input tanggal `36px` (dan `44px` pada layar sempit `<= 700px`).
5. **Header Minimal & Tabel Pemeriksaan Ringkas dengan Ikon Catatan per Sel (`src/utils/review.ts`, `src/utils/revision.ts`, `src/pages/Admin.tsx`, `src/admin.css`, `src/components/Icon.tsx`, `src/types/index.ts`)**
   - Header modal pemeriksaan `.admin-review-modal-header.is-minimal` hanya menampilkan tombol ikon kembali (`arrowLeft`) di pojok kiri dan tombol ikon tutup (`✕`) di pojok kanan; tombol kembali (`backFromReview`) kembali ke `DetailModal` jika dibuka dari `Lihat Detail -> Periksa`, atau kembali ke halaman Admin sebelumnya.
   - Modal pemeriksaan `.admin-review-modal.is-table-mode` kini memakai format tabel resmi ringkas menyerupai `Lihat Detail` (12 kolom untuk `Laporan Triwulan`, 7 kolom untuk `Sasaran Kinerja` termasuk fallback tanpa `criteriaData`), sehingga seluruh Program dan multi-Sasaran (`rowSpan`) langsung terlihat dalam satu tabel tanpa sidebar maupun panel tab bertumpuk.
   - Setiap sel indikator menyediakan tombol ikon catatan kecil (`.admin-cell-note-btn`, ikon `note`) yang membuka panel editor catatan di bagian bawah sebelum footer (`.admin-review-note-dock`) serta menampilkan pratinjau catatan di dalam sel. `Riwayat pemeriksaan` dan ringkasan footer menyertakan lokasi Program dan Sasaran.
6. **Penyelarasan Ukuran Pop-up, Tata Letak, dan Tabel `DetailModal` serta Header Berwarna Laporan Triwulan (`src/index.css`, `src/admin.css`)**
   - Seluruh pemakaian `DetailModal` (halaman verifikasi Admin `Laporan Triwulan` dan `Sasaran Kinerja`, `RiwayatLaporan`, serta pratinjau draf pada halaman input) disamakan proporsinya dengan tampilan modal pemeriksaan (`min(1240px, 96vw)`, tinggi `92vh`, latar scroll `#f9fafc` dengan padding `16px 18px 18px` dan jarak vertikal konsisten).
   - Tabel 7 kolom (`Sasaran Kinerja`) mempertahankan header `#eaf0f7` / teks `#36455e` ukuran `11px` serta banner kriteria `#e6f0fc` / `#2864ca`. Tabel 12 kolom (`Laporan Triwulan`) pada `DetailModal` maupun halaman **Periksa** (`.admin-review-triwulan-table`) sama-sama memakai pewarnaan judul kolom per kelompok: kolom 1-7 biru (`#e2edfc` / `#163d7a`), kolom 8-10 ungu (`#ede9fe` / `#4c2889`), kolom 11 hijau kalem (`#e1f5ea` / `#155638`), dan kolom 12 kuning kalem (`#fef5d4` / `#6b4b08`), dengan subheader nomor kolom `#ffffff` dan pembungkus sudut `10px`. `src/pages/Admin.tsx` dan `src/components/DetailModal.tsx` tidak perlu diubah untuk pembaruan gaya ini.

## Temuan Audit (Mode `after`)

1. **HIGH (Diselesaikan pada pembaruan gaya `DetailModal`): Kontras warna teks pendukung pada banner revisi dan header tabel 7-kolom `Sasaran Kinerja` di `DetailModal` sebelumnya berada di bawah standar WCAG AA 4.5:1 (R-25).**
   - Catatan pembaruan: Setelah penyelarasan `src/index.css`, seluruh pasangan warna `DetailModal` terverifikasi di atas 4.5:1 (`>= 5.0:1` pada `.revision-alert > span`, `8.91:1` pada `.revision-alert p`, `8.44:1` pada header `Sasaran Kinerja`, `8.95:1` / `8.97:1` / `7.62:1` / `7.3:1` pada header 4 kelompok kolom `Laporan Triwulan`, `10.69:1` pada baris kriteria, `5.58:1` pada lencana nomor kriteria, dan `7.36:1` pada `.detail-drawer .cell-note`).

2. **HIGH: Ukuran target sentuh tombol `Lihat Detail` di tabel verifikasi dan tombol tutup `×` pada modal detail di viewport mobile masih di bawah 44px (R-03).**
   - Bukti: Pada `@media (max-width: 760px)`, `src/admin.css:3458-3460` mengatur `#root .app-shell .admin-page .admin-table-wrap .admin-table-actions button { min-height: 38px; }` (`< 44px`), dan `src/index.css:664` mempertahankan `.detail-drawer .detail-close-btn` pada `34px x 34px` (`< 44px`).

3. **HIGH: Fokus awal keyboard saat `DetailModal` dibuka jatuh ke tombol backdrop tak terlihat `.overlay-close`, bukan ke kontrol di dalam dialog (R-32).**
   - Bukti: `src/utils/useDialog.ts:29` memfokuskan elemen interaktif pertama di dalam `.detail-overlay`, dan `src/components/DetailModal.tsx:57-61` menempatkan `<button className="overlay-close" ... />` sebelum `.detail-drawer`.

4. **HIGH: Posisi tombol tutup dan lebar kartu daftar program di modal pemeriksaan Admin (`.admin-review-modal`) belum optimal pada layar mobile `390x844` (R-03).**
   - Bukti: `src/admin.css:2336-2340` memosisikan `.admin-review-header-actions` dengan `top: 12px; right: calc(2.5vw + 12px);` sehingga ikon `✕` mendekati tepi atas luar header, dan `src/admin.css:2376-2379,3322-3324` memberi tombol program lebar tetap `220px` dengan `max-height: 126px` yang membuat satu program tampil setengah lebar dan mepet dengan batas bawah panel daftar program.

5. **MEDIUM: Tombol `Periksa` pada `DetailModal` Admin dan `Kirim Perbaikan` memakai ikon panah kanan dekoratif tanpa alasan tertulis di `DESIGN.md` (R-08).**
   - Bukti: `src/components/DetailModal.tsx:1304,1323` menempatkan `<Icon name="arrow" size={16} />` pada tombol `Kirim Perbaikan` dan `Periksa`.
